## Cách chạy

Cài Node.js, mở thư mục `phan-a` trong VS Code, mở Terminal và chạy:

```bash
npm install
npm run dev
```

Mở đường dẫn hiện trong Terminal, thường là http://127.0.0.1:5173.

Nhấn Ctrl + C trong Terminal để dừng chương trình.
